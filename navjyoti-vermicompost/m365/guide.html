Setting up the tracker on Microsoft 365

SharePoint holds the registers, Power Apps is the phone app for supervisors, Power BI gives the live reports, and Power Automate sends alerts. Everyone uses their company login. Allow about 1–2 days in total.

About the pictures: they are simplified drawings of each screen, not screenshots. Microsoft changes button positions from time to time, so look for the same words if a screen looks a little different. The orange numbered markers match the numbered steps.

Stage 1

Create the SharePoint site

IT admin · 10 minutes
  1. Go to office.com → SharePoint → + Create site.
  2. Choose Team site. It also creates a matching Microsoft Teams team.
  3. Name it Navjyoti Production. Note the site address.
  4. Add supervisors as Members (can edit) and managers as Visitors (view only).
Stage 2

Create the 10 lists and load Batch 4

IT admin · 20 minutes
  1. Install PowerShell 7 from the Microsoft Store, open it, and run the install command.
  2. A Microsoft 365 admin registers the PnP app once. Replace yourcompany with the name in your SharePoint address (https://yourcompany.sharepoint.com). A browser window opens to sign in and approve; then copy the Client ID it shows.
  3. Unzip the kit, then in PowerShell go to that folder with cd (not C:\Windows\System32). Run the Navjyoti script, replacing yourcompany with your own SharePoint name and PASTE-CLIENT-ID-HERE with the Client ID from step 2.
  4. Open Site contents and check the item counts: RawMaterial 15, PreCompost 3, Beds 80, Harvest 80, QualityControl 6, Sales 6, StockLedger 63, Expenses 30, Batches 2, DailyLog 0.
Install PnP PowerShell
Install-Module PnP.PowerShell -Scope CurrentUser
Register the app (admin, once)
Register-PnPEntraIDAppForInteractiveLogin -ApplicationName "PnP Navjyoti" -Tenant yourcompany.onmicrosoft.com
Go to the unzipped kit folder (example path)
cd "$env:USERPROFILE\Downloads\Navjyoti_M365_Kit"; Get-ChildItem -Recurse | Unblock-File
Create the lists and load Batch 4
./Create-NavjyotiLists.ps1 -SiteUrl https://yourcompany.sharepoint.com/sites/NavjyotiProduction -ClientId PASTE-CLIENT-ID-HERE
Stage 3

Build the data-entry app in Power Apps

Power user · 2–3 hours
  1. Go to make.powerapps.com → + Create.
  2. Choose Start with data.
  3. Pick SharePoint and your Navjyoti Production site.
  4. Tick DailyLog → Create. Power Apps builds a working phone app. Then add the other lists under Data → + Add data.
  5. Add the bed board: a gallery with the Items formula shown, coloured by status. All formulas are in PowerApps-Formulas.md in the kit.
  6. Supervisors tap a bed…
  7. …and a pop-up panel opens with its details and a Save button. Publish and share the app with the team.

Stage 4

Build the reports in Power BI

Power user · 3–4 hours
  1. Open Power BI Desktop → Get data.
  2. Choose SharePoint Online list.
  3. Paste the site address.
  4. Select Implementation 2.0, tick all 10 lists, then Transform data → Close & apply.
  5. In Model view, drag Batches[BatchCode] onto each list's Batch column. Paste the measures from PowerBI-Measures.dax.
  6. Build the pages with a Batch slicer: Overview, Raw material, Beds & harvest, Quality, Sales & stock, Compare batches.
  7. For the Quality page, put Product (RM / FG / EX) on the legend and add constant lines at the FCO limits. Turn on tooltips and add a drill-through page for pop-up detail.
  8. Publish. In app.powerbi.com open the semantic model Settings and set the credentials to OAuth2.
  9. Turn on scheduled refresh (up to 8 times a day).
Stage 5

Set up alerts in Power Automate

Power user · 1 hour
  1. + Create → Scheduled cloud flow, every day at 08:00.
  2. Add SharePoint – Get items on Beds with the filter shown.
  3. Add a Condition: number of items greater than 0.
  4. Add Teams – Post message with the list of overdue beds. Repeat for watering gaps, FG/EX reports outside FCO and unpaid raw material (see PowerAutomate-Flows.md).
Stage 6

Put it together in Teams

Anyone · 10 minutes
  1. In the Navjyoti Production team, click + on the tab bar.
  2. Add Power Apps (the app), Power BI (the dashboard) and Lists (Beds, Harvest) as tabs.
Stage 7

Go live with Batch 5

Whole team · 1–2 weeks
  1. Fill in Batch 5's start date and stage in the Batches list.
  2. From now on, supervisors enter daily logs, beds, harvests, lab reports and sales in the app.
  3. Keep the Excel tracker running alongside for 1–2 weeks and compare the totals with Power BI.
  4. Once they match, use Microsoft 365 as the main system.
